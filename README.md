### 🚀 Telefona Kurulum Adımları
1. Telefonunuzun tarayıcısından yukarıdaki doğrudan indirme linkine dokunun.
2. İndirme bittiğinde bildirimden veya **İndirilenler (Downloads)** klasöründen `NoteApp-debug.apk` dosyasına tıklayın.
3. Android sistemi güvenlik uyarısı verirse *"Bu kaynaktan yüklemeye izin ver"* seçeneğini aktif edin.
4. **Yükle (Install)** butonuna basarak uygulamayı kullanmaya başlayın!
